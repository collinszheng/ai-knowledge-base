# AI 辅助开发软件项目学习清单

> 从工具操作、提示词、工程化到安全合规的 8 模块实战指南
---

## 1. AI 编程工具操作

### 必学

- Cursor / VS Code + Copilot / Windsurf 的基本操作
- Tab 补全、行内编辑、Chat、Composer / Agent 模式
- `@文件`、`@文件夹`、`@Code`、`@Docs`、`@Web` 的用法
- 如何让 AI 只读相关文件，而不是塞整个项目
- 如何查看、接受、拒绝 AI 生成的 diff
- 规则文件：`.cursorrules`、`CLAUDE.md`、`AGENTS.md`
- 终端 AI：Claude Code、Aider、Codex CLI 的初始化、生成补丁、运行命令、提交
- Git 基础：分支、diff、stash、回滚、PR

### 练到什么程度

能在 10 分钟内配置好环境，并让 AI 安全地修改一个文件。

---

## 2. 提示词与任务拆解

### 必学

- 提示词结构：角色、背景、目标、约束、验收标准、输出格式
- “先出计划，再写代码”
- 把大需求拆成 5–10 个可验证的小任务
- 任务卡写法：改哪些文件、怎么验证、不要改什么
- 上下文管理：只给必要信息，分块喂给 AI
- 防幻觉：要求引用文件行号、给验证方法、不要直接改代码

### 练到什么程度

拿到一个需求，能写出 AI 能执行的任务清单，而不是让 AI 随机生成。

---

## 3. 软件工程基础

AI 可以帮你写，但你必须懂，否则无法审查。

### 必学

- 需求：用户故事、验收标准
- 架构：分层、模块化、接口设计
- 代码质量：命名、小函数、单一职责、错误处理
- 测试：单元测试、集成测试、端到端测试、mock
- 调试：读栈、看日志、二分定位、最小复现
- 重构：提取函数、消除重复、保持行为不变
- 文档：README、API 文档、注释

### 练到什么程度

能判断 AI 写的代码对不对、能不能合并。

---

## 4. AI 辅助具体工作流

### 必学

- 新功能：先写测试 → AI 实现 → 运行 → 审查 → 提交
- 修 bug：复现 → 日志 → 让 AI 列假设 → 验证 → 修复 → 回归测试
- 重构：测试保护 → 小步改 → 对比行为
- Code Review：让 AI 查 bug、安全、性能、可读性，你最终决定
- 让 AI 生成提交信息、PR 描述、发布说明
- 让 AI 解释旧代码、画架构图、写文档

### 练到什么程度

每个改动都小到可运行、可回滚、可测试。

---

## 5. 自动化与集成

### 必学

- CI/CD：GitHub Actions 的 lint、test、build、deploy
- 让 AI 读 CI 日志并修复失败
- 依赖管理：升级、漏洞扫描
- 部署：Docker、Vercel、Railway、云服务器
- MCP：连接文件系统、数据库、浏览器、API
- Agent 工作流：自动修 CI、生成文档、升级依赖

### 练到什么程度

能让 AI 帮你跑通“提交 → 测试 → 部署”的自动化流程。

---

## 6. 安全与合规

### 必学

- 密钥管理：`.env`、不提交、不发给 AI
- 数据隐私：脱敏、本地模型
- 代码安全：注入、XSS、越权、依赖漏洞
- 许可证：MIT、GPL、Apache 的区别
- AI 代码版权与合规

### 练到什么程度

AI 生成的代码，你能判断有没有安全风险。

---

## 7. 团队协作规范

### 必学

- 规则文件：`CLAUDE.md`、`.cursorrules`、`AGENTS.md`
- 哪些代码能让 AI 写，哪些必须人工
- PR 流程、审查清单
- 提示词库、知识库
- 如何让 AI 遵守项目规范

### 练到什么程度

别人用你的规则文件，也能让 AI 按同样规范工作。

---

## 8. 评估与持续改进

### 必学

- 记录有效提示词和失败案例
- 度量：时间节省、bug 率、测试覆盖率
- 每周复盘：哪些 AI 用法有效，哪些无效
- 建立个人 AI 开发手册

### 练到什么程度

形成一套可复用的 AI 辅助开发系统，而不是每次从零开始。

---

## 最小必学清单

如果你只想先学最核心的：

1. Cursor / Copilot 基本操作 + `@文件`
2. 写任务卡：背景、目标、约束、验收标准
3. Git 分支、diff、提交、回滚
4. 单元测试 + 让 AI 修 bug
5. Code Review：让 AI 查 bug，你决定合并
6. `.cursorrules` / `CLAUDE.md` 规则文件
7. 密钥不发给 AI
8. GitHub Actions 跑测试
