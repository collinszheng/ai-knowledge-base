## 1. 读论文的方法

> 大多数论文不值得精读，**快速判断「值不值得读」本身就是核心技能**。

### 必学

**三遍读法**

- [ ] 第一遍（5–10 分钟）：标题、摘要、图表、结论 —— 只回答「它想解决什么」
- [ ] 第二遍（30–60 分钟）：方法与实验设计 —— 只回答「它怎么做的、证据够不够」
- [ ] 第三遍（按需）：公式推导与实现细节 —— 只对**真的要用**的论文做
- [ ] 明确大多数论文在第二遍就该停

**抓重点**

- [ ] **先看图**：架构类论文的关键信息常在结构图与结果表里，不在正文
- [ ] 定位「它反对谁」：一篇论文的贡献只有相对前作才成立
- [ ] 区分**声称**与**证据**：结论句能不能被它自己的实验支撑
- [ ] 看实验基线是否公平（有没有挑软柿子、有没有缺关键对照）
- [ ] 看数据与规模：小规模实验的结论能不能外推
- [ ] **公式要能手推**：遇到核心公式先合上论文自己推一遍，再对答案
- [ ] 判断可复现性：代码放了吗、算力要求多少、数据能拿到吗

**时间与心态**

- [ ] 给单篇设预算（初读 ≤ 90 分钟、写笔记 ≤ 60 分钟），超时就先记存疑点
- [ ] 不懂的地方**不要跳过，写进笔记的「存疑」节** —— 那是下次的入口
- [ ] 允许自己判定「不值得读」（结论已被普遍接受且无新机制）
- [ ] 把论文挂到已有脉络上：它和我读过的哪篇是同一根线

### 练到什么程度

能用 **5 分钟**讲清一篇论文：反对谁、做了什么、证据是什么、**可能的弱点在哪**。

## 2. 架构

> 这一组是主线。**Attention Is All You Need 必须精读到能默写。**

### 必学

**奠基**

- [ ] 2017 · **Attention Is All You Need** —— 逐节读，读后能默写一层结构
- [ ] └ 读后回答：为什么必须去掉循环？作者用什么实验证明注意力本身就够
- [ ] └ 读后回答：多头注意力的必要性，论文给了什么证据（消融表）
- [ ] 2018 · **GPT-1** —— 看懂「无监督预训练 + 有监督微调」两阶段范式
- [ ] 2019 · **GPT-2** —— 规模带来的零样本能力，以及作者为何措辞谨慎
- [ ] 2020 · **GPT-3** —— in-context learning 的提出与 few-shot 的实验设计
- [ ] └ 读后回答：为什么「不更新参数」也能完成新任务，论文的解释是什么
- [ ] 2021 · **Gopher** —— 大规模训练的工程细节与评测体系（当参考手册读）

**规模规律与开源谱系**

- [ ] 2022 · **Chinchilla** —— 固定算力下参数量与 token 数的最优配比
- [ ] └ 读后回答：为什么 GPT-3 175B 在此标准下是「训练不足」的
- [ ] 2023 · **LLaMA** —— 用公开数据 + 更长训练追平更大模型的思路
- [ ] 2023 · **LLaMA 2** —— 对齐流程与安全策略的工程披露
- [ ] 2024 · **LLaMA 3** —— 数据规模与配比的最新实践

### 练到什么程度

能画出 GPT 系的**演进图**：每一代相对上一代改了什么、哪些是规模红利、哪些是架构红利。

## 3. 训练与效率

> 这一组决定你「跑得起什么」。**FlashAttention 与 RoPE 是必读中的必读。**

### 必学

**注意力与位置**

- [ ] 2019 · **Transformer-XL** —— 段级循环与相对位置编码的动机
- [ ] 2021 · **RoFormer / RoPE** —— 用旋转把相对位置编码进点积
- [ ] └ 读后回答：RoPE 为什么天然带相对位置性质
- [ ] 2022 · **FlashAttention** —— IO 感知的分块计算，为什么结果不变却更快
- [ ] └ 读后回答：瓶颈在显存带宽而非算力，这句话具体指什么
- [ ] 2023 · **GQA** —— 多个 query 头共享 KV 头，省的是显存还是算力

**训练系统**

- [ ] 2019 · **ZeRO** —— 优化器状态 / 梯度 / 参数分片三阶段
- [ ] 2020 · **DeepSpeed** —— 工程实现与显存墙的实际解法
- [ ] 训练并行策略综述性阅读：数据 / 张量 / 流水线并行各切什么

**参数高效微调**

- [ ] 2021 · **LoRA** —— 低秩假设从哪来、实验如何支撑
- [ ] └ 读后回答：为什么低秩更新就够（论文给的直觉解释是什么）
- [ ] **QLoRA** —— 4-bit 量化 + LoRA，以及它牺牲了什么

### 练到什么程度

能对着任一模型的配置，说出它**用了哪些效率技巧**，以及分别省的是显存、算力还是通信。

## 4. 对齐

> 一条主线：**怎么把「预测下一个词」变成「按人类偏好回答」。**

### 必学

- [ ] 2017 · **RLHF 的原始工作**（Christiano 等，从人类偏好学奖励） —— 偏好建模的起点
- [ ] 2022 · **InstructGPT** —— 三阶段流程（SFT → 奖励模型 → PPO）的完整范式
- [ ] └ 读后回答：KL 惩罚在目标函数里的作用，去掉会怎样
- [ ] └ 读后回答：论文如何证明「1.3B 对齐后胜过 175B 未对齐」
- [ ] 2023 · **DPO** —— 把 RLHF 化简为一步分类损失
- [ ] └ 读后回答：DPO 隐含的奖励函数是什么、它省掉了哪个模型
- [ ] └ 读后回答：DPO 相比 PPO 的代价与失效场景
- [ ] 2024 · **GRPO**（DeepSeekMath 起） —— 去掉 critic、用组内相对优势
- [ ] 对齐税：安全对齐与能力之间的张力，论文里的证据

### 练到什么程度

能在白板上写出 **PPO 与 DPO 的目标函数对比**，并指出两者优化的是同一个东西的什么变换。

## 5. 推理与能力

> 这一组最好读、也最容易被高估 —— 注意区分「效果提升」与「机制解释」。

### 必学

- [ ] 2022 · **Chain-of-Thought** —— 中间步骤为什么有用，在哪些任务上有效
- [ ] └ 读后回答：论文的收益来自「更多计算」还是「结构化分解」
- [ ] 2022 · **Self-Consistency** —— 多次采样投票，代价与收益的关系
- [ ] 2022 · **ReAct** —— 推理与行动交替，为后来的 agent 范式奠基
- [ ] 2023 · **Tree of Thoughts** —— 搜索式推理，以及它的成本量级
- [ ] 2022 · **Emergent Abilities** —— 「涌现」的原始主张
- [ ] └ **对照阅读**：后续质疑「涌现是度量方式造成的」的批评工作
- [ ] └ 读后回答：这场争论里，双方对「能力」的定义差在哪

### 练到什么程度

能对「大模型到底有没有在推理」给出**有依据的回答**，并主动说清自己证据的强弱。

## 6. 检索增强

> 如果你做应用，这一组优先级最高 —— 它直接对应[应用清单](/03-AI应用开发/学习清单)里的 RAG 模块。

### 必学

- [ ] 2020 · **RAG** —— 参数化 + 非参数化记忆的结合，原始动机
- [ ] └ 读后回答：论文里的检索器是怎么训的，和今天工程里的做法差在哪
- [ ] 2020 · **REALM** —— 把检索器一起预训练的路线
- [ ] 2020 · **DPR** —— 双塔稠密检索，以及它取代 BM25 的边界
- [ ] └ 读后回答：稠密检索在什么查询上会输给 BM25（呼应混合检索的动机）
- [ ] 后续脉络选读：重排（cross-encoder）、查询改写、多跳检索

### 练到什么程度

能说清「今天工程实践里的 RAG」与「论文里的 RAG」**在训练方式上的关键差别**。

## 7. 笔记产出与维护

> 论文笔记的价值全在**可检索、可回溯、带质疑**。命名规范见 [论文笔记索引](/06-论文笔记/)。

### 必学

**每篇笔记的必填节**

- [ ] **一句话结论**：这篇论文最该记住的一件事
- [ ] 解决什么问题 / 反对谁
- [ ] 关键方法（能用自己的话复述，不抄摘要）
- [ ] 实验与证据（数据集、基线、关键数字）
- [ ] **我的质疑**：基线公平吗？结论能外推吗？有没有更简单的解释
- [ ] 可复现性：代码、算力、数据是否可得
- [ ] **存疑清单**：没看懂的地方（不许留空）
- [ ] 关联笔记：与哪些已读论文是同一脉络

**规范与维护**

- [ ] 命名遵循 `年份-会议-简称.md`（例 `2017-NeurIPS-AttentionIsAllYouNeed.md`）
- [ ] 用[论文笔记模板](https://github.com/collinszheng/ai-knowledge-base/blob/main/_templates/论文笔记模板.md)起步，不要即兴发挥格式
- [ ] 每写 5 篇就回头**合并同类项**（把重复的概念抽成独立笔记）
- [ ] 维护 `06-论文笔记/README.md` 里的「待读清单」，读完就挪位置
- [ ] 允许写「这篇我没读懂」——那也比假装读懂有价值

### 练到什么程度

**三个月后翻开自己的笔记，能不看原论文就复述它的方法与你当时的质疑。**

## 最小必学清单

如果你只想先读最核心的：

1. 三遍读法：第一遍只问「它解决什么」
2. **Attention Is All You Need** —— 精读到能默写
3. **Chinchilla** —— 参数量与 token 数怎么配
4. **RoPE** —— 相对位置怎么进点积
5. **FlashAttention** —— 瓶颈在带宽而非算力
6. **LoRA** —— 低秩假设
7. **InstructGPT** —— 三阶段对齐范式
8. **DPO** —— 相比 PPO 的化简与代价
9. **Chain-of-Thought** + 对「涌现」的批评性阅读
10. **RAG（2020）** —— 与今天工程做法的差别
11. 每篇都写出「我的质疑」一节
