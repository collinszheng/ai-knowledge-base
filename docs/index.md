## 建议的学习路线

按这个顺序推进，前面的内容是后面的前置知识：

```text
阶段一 · 地基
  线性代数 → 概率统计 → 微积分与梯度 → Python / NumPy → PyTorch 基础
        ↓
阶段二 · 原理
  神经网络 → 反向传播 → 序列模型(RNN/LSTM) → Attention → Transformer
        ↓
阶段三 · 大模型
  GPT 系架构 → Tokenizer → 预训练目标 → SFT → RLHF / DPO → 推理优化(量化/KV Cache)
        ↓
阶段四 · 工程应用
  Prompt 工程 → Embedding 与向量检索 → RAG → Agent / Function Calling → 评测与可观测性
        ↓
阶段五 · 前沿
  论文精读 → 复现实验 → 自己的小项目
```

**横向专题：** [AI 辅助工程](/06-AI辅助工程/) —— 不绑定任何阶段，从第一天就可以开始用，越早越好。

## 怎么用这个站

- **左侧边栏**按分区列出全部笔记；进到某个分区后，底部的「其他分区」可以快速跳走
- **右上角搜索**是全文检索，中文按词切分（搜「注意力」能找到「注意力机制」），不需要联网
- 每篇笔记右侧有**本页目录**，页脚有**最后更新于**和上一篇 / 下一篇
- 想改哪篇，点页脚的「在 GitHub 上编辑此页」直接改，改完提交就会自动重新发布
