## 项目档案

做过的项目记在这里，一个项目一份：`项目-<项目名>.md`。

放**只对这个项目成立**的东西：要解决什么问题、当时的取舍、砍掉了什么、踩了什么坑。其中提炼出来、换个项目还能用的部分，搬到 [07 · 可复用资产](../07-可复用资产/)。

> 必须是这样平铺的文件名，**不能建成子目录** —— 站点侧边栏只扫分区目录的一级 `.md`。

- [项目-体重日记](./项目-体重日记.md) —— 纯本地 Android 体重记录 App；[07 · 可复用资产](../07-可复用资产/) 里第一批页面大半是从它提炼出来的
