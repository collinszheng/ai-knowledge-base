# 大模型学习清单

> **一句话结论：** 大模型的「懂」有三个硬指标 —— **能把 Attention 手推一遍、能把 KV Cache 的显存算出来、能说清 RLHF 和 DPO 在优化同一个东西的什么差别**。达不到这三条，读再多综述也只是熟悉名词。
>
> 从注意力机制、Transformer 架构、分词、预训练到对齐与推理优化的 7 个模块实战清单
> 最后更新：2026-10-13 ｜ 标签：`#大模型` `#Transformer` `#学习清单`

**怎么用：** 每条前面的复选框勾掉即代表练过。模块 1、2 是地基，**必须动手推**；3–5 讲训练侧，6 讲推理侧，可以按兴趣选。第 7 节是「现象层」，适合拿来检验自己前面到底学没学懂。如果只想要最核心的，直接跳到文末的[最小必学清单](#最小必学清单)。

## 1. 序列建模与注意力

> 先搞清「Attention 解决了什么痛苦」，再看它的公式。反过来学，公式只是符号。

### 必学

**从 RNN 到 Attention**

- [ ] RNN 的建模方式，以及它的两个固有缺陷：**无法并行**、**长程依赖衰减**
- [ ] LSTM / GRU 的门控在解决什么（以及它并没有真正解决长程依赖）
- [ ] Seq2Seq 的 encoder–decoder 结构与**信息瓶颈**：整个句子被压进一个定长向量
- [ ] Attention 最初的动机：让解码器直接看到编码器的**全部**中间状态
- [ ] 交叉注意力（cross-attention）与自注意力（self-attention）的区别

**自注意力机制**

- [ ] Q、K、V 各自在算什么 —— 用一句话说清，不用公式
- [ ] 缩放点积注意力：**为什么必须除以 `sqrt(d_k)`**（方差角度而非「让数值变小」）
- [ ] Softmax 在这条链路上的作用，以及它为什么导致注意力更「尖锐」
- [ ] Multi-Head：为什么要多头（多子空间假设），以及它和单头大维度的区别
- [ ] 注意力的复杂度 `O(n²d)`：长序列的代价具体花在哪一步
- [ ] Padding mask 与 causal mask 的区别，以及它们分别加在 softmax 之前还是之后
- [ ] 权重共享：QKV 投影矩阵能不能合并、合并后有什么差别

**位置信息**

- [ ] 为什么自注意力本身**完全不知道顺序**
- [ ] 正弦位置编码的构造与它「能外推」的说法是否成立
- [ ] 可学习位置编码的局限
- [ ] 相对位置编码的动机
- [ ] RoPE：旋转矩阵怎么把「相对位置」编码进点积
- [ ] ALiBi：为什么用线性偏置就够了

### 练到什么程度

**能手写 scaled dot-product attention**（含 mask、含多头拆分与拼接），并解释清楚 `sqrt(d_k)` 的作用和去掉它会怎样。

反例：「Attention 就是加权求和」。
正例：「QKᵀ 得到相似度矩阵，除以 `sqrt(d_k)` 是因为点积方差随维度线性增长，不缩放会让 softmax 进入饱和区、梯度趋近 0」。

## 2. Transformer 架构

> 目标是**默写**而不是**认图**。看架构图谁都会，白纸上画出来才算。

### 必学

**结构拆解**

- [ ] 三种体系的分工：Encoder-only（BERT 系）、Decoder-only（GPT 系）、Encoder-Decoder（T5 系）
- [ ] 一层 Transformer 的完整数据流：Embedding → Attention → 残差 → Norm → FFN → 残差 → Norm
- [ ] **残差连接解决什么**：为什么 100 层网络能用 SGD 训起来
- [ ] Post-LN vs Pre-LN：为什么现在默认 Pre-LN（训练稳定性）
- [ ] LayerNorm 与 RMSNorm：RMSNorm 省掉了什么、为什么还能 work
- [ ] FFN 的中间维度通常是 `4×hidden`，以及这个比例从哪来
- [ ] 激活函数：ReLU / GELU / SwiGLU，以及 SwiGLU 为什么常配 `8/3×` 而非 `4×`
- [ ] 输出层的权重绑定（embedding ↔ lm_head）
- [ ] 归一化放哪（attention 前 / FFN 前 / 最后）的实际差异

**规模与效率**

- [ ] 参数量估算：`embedding + layers × (attention + FFN)` —— 能手算一个 7B 的量级
- [ ] 前向 FLOPs 估算：为什么约等于 `2 × 参数量 × token 数`
- [ ] 层数 / 宽度 / 头数的典型比例，以及 Deep-and-Thin vs Shallow-and-Wide 的取舍
- [ ] MoE（混合专家）：稀疏激活的动机、路由机制、负载均衡问题
- [ ] 上下文窗口扩展的基本手段（位置插值、RoPE 缩放——知道思路即可）

### 练到什么程度

不看任何资料，**在白纸上默写一层 Transformer 的结构并标注每个张量的形状**；能手算一个 7B 模型的参数量，误差在一个量级内。

> **检验方法：** 用 Karpathy 的 `nanoGPT` 或类似实现写一遍自己的 GPT，跑通一个小语料的训练。

## 3. 分词与表示

> 分词是最容易被跳过、又最容易解释离奇现象的一节。

### 必学

- [ ] 为什么需要子词：词级词表的 OOV 问题与字符级序列过长
- [ ] **BPE 的训练算法**：反复合并最高频的相邻符号对
- [ ] WordPiece 与 BPE 的差别（合并准则不同）
- [ ] Unigram LM 分词：为什么它是「从大词表往下删」
- [ ] SentencePiece 的设计：为什么把空格也当成普通字符
- [ ] 词表大小的影响：太小 → 序列变长；太大 → embedding 参数膨胀且长尾稀疏
- [ ] 中英文词表效率差异：一个汉字可能占 1–3 个 token，这会带来什么后果
- [ ] 特殊 token：`BOS` / `EOS` / `PAD` / `UNK`，以及 **chat template** 的格式必须与训练时一致
- [ ] 换 tokenizer 等于换模型（权重与词表是绑定的）
- [ ] 分词导致的典型 LLM 缺陷：数数、拼写、字符级操作

### 练到什么程度

能用 `tokenizers` 或 `sentencepiece` **从零训练一个小词表**，并解释「GPT 数不清 `strawberry` 里有几个 r」的机制。

## 4. 预训练

> 这一节多数人跑不起全流程，但**必须懂**，否则无法判断一个模型是怎么来的、局限在哪。

### 必学

**目标与数据**

- [ ] 自回归语言建模目标：最大化下一个 token 的对数似然
- [ ] Causal mask 的实现方式，以及它和「不能看未来」的对应关系
- [ ] 数据管线：抓取 → 去重（精确 / 模糊）→ 质量过滤 → 配比
- [ ] 数据规模与模型规模的匹配关系
- [ ] 数据污染：测试集泄漏进训练集会让评测结果虚假变好

**规律与稳定性**

- [ ] Scaling Laws：损失与参数量、数据量、算力的幂律关系
- [ ] **Chinchilla 的结论**：给定算力，参数量与训练 token 数应大致同比例增长
- [ ] 为什么说 GPT-3 175B 按 Chinchilla 标准是「训练不足」的
- [ ] 训练不稳定：loss spike 的常见成因、回滚与重跑策略
- [ ] 梯度裁剪、学习率 warmup 在大规模训练里的必要性

**并行与显存**

- [ ] 数据并行 / 张量并行 / 流水线并行分别切什么
- [ ] ZeRO 的三个阶段各切什么（优化器状态 / 梯度 / 参数）
- [ ] 混合精度：bf16 与 fp16 的区别、为什么 bf16 更省心
- [ ] 梯度累积：用时间换显存
- [ ] 梯度检查点（activation checkpointing）：用算力换显存
- [ ] 训练成本估算：GPU 小时、有效 FLOPs 利用率

### 练到什么程度

能回答：「要训一个 1B 模型，大致需要多少 token、多少 GPU 小时？」并说清估算里用了哪些假设。**能用 LoRA 在一个小数据集上跑通一次真实微调**，即使只有单卡。

## 5. 微调与对齐

> 三阶段（预训练 → SFT → 偏好对齐）各自解决什么问题，是这一节的主线。

### 必学

**SFT（指令微调）**

- [ ] 三阶段的分工：预训练给「语言能力」、SFT 给「听指令」、对齐给「符合偏好」
- [ ] SFT 数据格式：instruction / input / output，以及 chat template 的构造
- [ ] **只在 response 上算损失**（mask 掉 prompt）—— 不这么做会怎样
- [ ] 灾难性遗忘与数据配比：为什么 SFT 之后通用能力会掉
- [ ] 数据质量 vs 数据数量的权衡（少量高质量常胜过大量噪声）
- [ ] LoRA / QLoRA 属于**参数高效微调**，不是对齐手段，别混淆

**偏好对齐**

- [ ] RLHF 的完整流程：收集偏好 → 训奖励模型 → PPO 优化策略
- [ ] PPO 的目标函数，以及 **KL 惩罚为什么不可省**（防 reward hacking、防跑偏）
- [ ] 去掉 KL 惩罚会发生什么（奖励暴涨、输出退化）
- [ ] DPO：怎么把 RLHF 变成一步分类损失、省掉了奖励模型和采样
- [ ] DPO 相比 PPO 的代价：依赖离线偏好数据、对数据分布更敏感
- [ ] GRPO：去掉 critic 的动机与它适合的场景
- [ ] 偏好数据来源：人工标注 vs AI 反馈（RLAIF）的取舍
- [ ] 对齐税（alignment tax）：安全对齐与能力之间的张力

### 练到什么程度

能说清 **DPO 相比 PPO 少了一个模型、多了一个什么隐含假设**；能解释「为什么奖励模型会被刷分」，以及 KL 惩罚在这里的作用。

## 6. 推理与效率

> 这一节最实用：决定你的模型能不能跑起来、一次能服务多少人。

### 必学

**解码**

- [ ] 自回归解码：一次一个 token，**为什么 decode 阶段是访存瓶颈而非算力瓶颈**
- [ ] 贪心 / Beam Search 的适用场景与代价
- [ ] 温度、Top-k、Top-p 的作用与组合使用
- [ ] 重复惩罚（repetition penalty）在解决什么
- [ ] Prefill 与 decode 两个阶段的特性差异（compute-bound vs memory-bound）

**KV Cache 与注意力加速**

- [ ] KV Cache 缓存的是什么、为什么能把复杂度从 `O(n²)` 降到 `O(n)`
- [ ] **KV Cache 显存公式**：`2 × layers × kv_heads × head_dim × seq_len × batch × dtype 字节`
- [ ] 给一个具体配置（如 7B / 8k / batch=1 / fp16）手算出显存占用
- [ ] GQA / MQA：多个 query 头共享 KV 头，省的是显存还是算力
- [ ] FlashAttention：为什么数学结果不变却更快（IO 感知 / 分块）
- [ ] PagedAttention 与连续批处理（continuous batching）解决什么

**量化与部署**

- [ ] 量化基础：INT8 / INT4，以及对称与非对称量化的区别
- [ ] GPTQ / AWQ / GGUF 各自的路子与适用场景
- [ ] 量化的代价：为什么有些任务掉点严重、有些几乎无损
- [ ] 投机解码（speculative decoding）：用小模型加速大模型的条件
- [ ] 推理框架选型：vLLM / SGLang / TGI / llama.cpp 的定位差异
- [ ] 吞吐 vs 延迟的权衡；为什么「加 batch」提升吞吐却恶化单请求延迟

### 练到什么程度

给「7B 模型、8k 上下文、batch=1、fp16」这组参数，**能在两分钟内估算出 KV Cache 的显存**，并解释为什么长上下文主要吃显存而不是算力。

## 7. 能力与现象

> 这一节是「验收层」。前面学懂了没有，看你能不能对这些现象给出有依据的解释。

### 必学

- [ ] 上下文学习（ICL）：为什么没更新任何参数也能学会新任务
- [ ] 思维链（CoT）：**在什么任务上有效、在什么任务上纯属浪费 token**
- [ ] 「涌现能力」是不是评测指标造成的幻觉（阈值型指标的争论）
- [ ] 幻觉的成因：训练目标优化的是似然而非事实
- [ ] 幻觉的另外两个来源：解码采样、知识边界外的强行作答
- [ ] 缓解幻觉：检索增强、工具调用、允许模型说「不知道」、生成后验证
- [ ] 长度泛化与位置外推：为什么超长上下文里模型会「忘掉中间」
- [ ] 知识截止：为什么模型对训练后的事件一无所知，以及这是否能靠提示词解决
- [ ] Benchmark 污染与「刷榜」：怎么判断一个分数是否可信
- [ ] **为什么模型格式能力很强、计算能力很弱**（回到第 3 节的分词）

### 练到什么程度

能对「大模型到底有没有在推理」给出一个**有依据**的回答，并主动说清自己证据的强弱 —— 而不是复述某一派的立场。

## 最小必学清单

如果你只想先学最核心的：

1. 手写 scaled dot-product attention（含 mask），并解释 `sqrt(d_k)`
2. 白纸默写一层 Transformer，标注每个张量的形状
3. QKV 各自在算什么，用一句话说清
4. 位置编码解决什么问题；RoPE 的基本思路
5. BPE 的训练算法；分词如何导致数值/拼写类缺陷
6. Chinchilla 的结论，以及参数量与 token 数怎么配
7. SFT 与偏好对齐的分工；**只在 response 上算损失**
8. DPO 相比 PPO 少了一个模型、多了什么假设
9. **KV Cache 显存公式**与 GQA 省在哪
10. 幻觉的三个成因与对应的缓解手段
