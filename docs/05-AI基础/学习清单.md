## 1. 数学基础

> 这一节的每一条都标了它在 AI 里的用处。**用不上就可以先跳过**，不用从头啃到尾。

### 必学

**线性代数**

- [ ] 矩阵乘法的几何意义：矩阵 = 线性变换，而不只是一堆数
- [ ] 张量维度记号约定：`(batch, seq, hidden)` 分别代表什么、为什么这么排
- [ ] 转置、逆、伪逆 —— 并知道深度学习里**几乎不求逆**（为什么？）
- [ ] 秩与线性相关：为什么低秩分解能压缩模型（LoRA 的直觉来源）
- [ ] 特征值 / 特征向量：它和「主要变化方向」的关系
- [ ] SVD 与低秩近似：LoRA 背后的数学
- [ ] 范数：L1 / L2 / Frobenius，以及权重衰减到底在惩罚什么
- [ ] 广播（broadcasting）规则 —— 维度不匹配的报错 90% 出在这
- [ ] `einsum`：把复杂张量运算写成一行，且不容易错

**概率统计**

- [ ] 条件概率与贝叶斯公式：先验、似然、后验各自是什么
- [ ] 期望、方差、协方差：BatchNorm 在标准化哪两个量
- [ ] 常见分布：伯努利、类别、高斯、多项分布，以及各自对应的损失函数
- [ ] 最大似然估计（MLE）：**为什么分类任务的交叉熵损失就是它**
- [ ] 交叉熵、KL 散度、相对熵：为什么 KL 不对称，以及这在实际中意味着什么
- [ ] 采样：温度、Top-k、Top-p 的统计学解释
- [ ] 蒙特卡洛估计：为什么采样能近似期望、方差怎么降

**微积分与优化**

- [ ] 偏导与梯度：梯度方向为什么是「上升最快」的方向
- [ ] 链式法则 —— 反向传播就是它的重复应用，没有别的魔法
- [ ] 雅可比与海森矩阵：**为什么二阶方法在大模型上不实用**
- [ ] 凸与非凸：为什么深度学习没有全局最优保证却还能 work
- [ ] 梯度下降族：SGD / Momentum / RMSProp / Adam / AdamW 各自修了什么问题
- [ ] 学习率调度：warmup、cosine，以及**为什么需要 warmup**
- [ ] 泰勒展开：为什么它能解释梯度下降为什么有效
- [ ] 拉格朗日乘子（了解即可，用于带约束的优化）

### 练到什么程度

能看懂一篇论文里的公式在算什么，并且**能用 20 行 NumPy 把它实现出来**。做不到也没关系，但要知道自己卡在哪一条上。

反例：「我学过线代」。
正例：「SVD 是把矩阵拆成旋转·缩放·旋转，LoRA 只更新低秩的那两个小矩阵，所以参数量从 `d×d` 降到 `d×r`」。

## 2. Python 与科学计算

> 这一节的目标不是「会写 Python」，而是**能把想法变成能跑的代码，且不因为语言细节浪费时间**。

### 必学

**Python**

- [ ] 数据结构与复杂度：为什么 `list` 查找是 O(n)、`dict` 是 O(1)
- [ ] 列表推导与生成器：处理大数据集时不爆内存
- [ ] 装饰器与上下文管理器：看懂框架源码里的 `@torch.no_grad()`
- [ ] 类型注解（`typing`）：让 AI 帮你改代码时的第一道保险
- [ ] 虚拟环境：`venv` / `uv` / `conda` 的取舍（详见[02 · 工具与环境](/02-工具与环境/)）
- [ ] 断点调试：`breakpoint()`、`pdb`、IDE 调试器 —— 比 `print` 高效得多
- [ ] 区分「代码慢」和「数据搬运慢」：先测量再优化

**NumPy**

- [ ] `ndarray` 的形状（shape）与轴（axis）语义 —— 尤其搞清 `axis=0/1` 到底消掉了哪一维
- [ ] 广播规则（与 PyTorch 完全一致，学一次两边通用）
- [ ] 向量化：把一个三重 for 循环换成一行
- [ ] 视图 vs 拷贝：`reshape` / `view` / 花式索引各自返回什么
- [ ] 随机数种子与可复现性
- [ ] `einsum` 与 `tensordot`
- [ ] 内存布局与转置的开销：为什么 `transpose` 常常不搬运数据

### 练到什么程度

拿到一个「算 attention 权重」的需求，能直接写出向量化实现，**且第一版就没有 for 循环**。

## 3. PyTorch 基础

> AI 领域最值得先花时间的一节。**PyTorch 熟不熟，直接决定你 debug 的速度。**

### 必学

**张量操作**

- [ ] 张量创建、`dtype`、`device`（cpu / cuda / mps）
- [ ] 形状操作全家桶：`view` / `reshape` / `permute` / `transpose` / `squeeze` / `unsqueeze` —— 并知道**哪个返回视图、哪个是拷贝**
- [ ] 索引与切片、`gather` / `scatter`、`masked_fill`、`masked_select`
- [ ] 广播与自动类型提升的坑（`float32` 和 `float64` 混用会静默变慢）
- [ ] `contiguous()` 什么时候必须调用

**自动微分**

- [ ] `requires_grad`、计算图是怎么建起来的
- [ ] `.backward()` 之后梯度存在哪、为什么会**累加**
- [ ] `optimizer.zero_grad()` 为什么必须调用（漏了会怎样）
- [ ] `torch.no_grad()` 与 `detach()` 的区别与各自场景
- [ ] 梯度裁剪 `clip_grad_norm_`

**模型与训练**

- [ ] `nn.Module`：`__init__` / `forward` / `parameters` / `state_dict`
- [ ] `nn.Linear`、`nn.Embedding`、`nn.LayerNorm` 常用层
- [ ] `CrossEntropyLoss` **内置了 softmax**，前面不要再加一层
- [ ] `Dataset` / `DataLoader` / `collate_fn` / `num_workers` / `pin_memory`
- [ ] 训练循环的标准骨架：train / eval / 保存 / 加载 / 早停
- [ ] `model.eval()` 到底改了什么（Dropout、BatchNorm 的行为）
- [ ] 设备管理：`.to(device)`、混合精度 `torch.autocast`
- [ ] 显存排查：`torch.cuda.memory_allocated()`，OOM 的常见三类原因
- [ ] 固定随机种子让实验可复现
- [ ] 保存与加载：`state_dict` vs 整个模型（为什么推荐前者）

### 练到什么程度

能不看教程，从零写出一个可训练的两层 MLP：定义模型、准备数据、训练、评估、保存、重新加载并推理。**报错时能自己定位到是形状问题、设备问题还是梯度问题。**

## 4. 深度学习入门

> 这一节的关键动作只有一个：**手推一遍反向传播**。推过和没推过，后面看论文是两种体验。

### 必学

- [ ] 感知机 → 多层网络：为什么单层解决不了 XOR
- [ ] 激活函数：为什么必须有非线性；ReLU / GELU / SiLU / Sigmoid / Tanh 各自的问题
- [ ] 万能近似定理（知道它成立，也知道它的限定条件）
- [ ] 损失函数：MSE 用于回归、交叉熵用于分类，**为什么不用 MSE 做分类**
- [ ] **反向传播：不查资料手推一遍两层全连接网络的梯度**
- [ ] 用 NumPy 手写一次前向 + 反向，与 PyTorch 的 `.grad` 对拍
- [ ] 参数初始化：为什么不能全零、Xavier / He 初始化在解决什么
- [ ] 动态计算图与静态图的区别：为什么动态图更易调试
- [ ] 残差连接：它解决的是「深层网络训不动」的哪个具体环节

### 练到什么程度

能在一张白纸上画出一个两层网络的前向与反向，并说清每一行的维度。**这一步过了，Transformer 的推导就只是更长的同类计算。**

## 5. 训练与调参

> 90% 的「模型不 work」不是模型的问题，是训练配置的问题。

### 必学

- [ ] 优化器家族对比：SGD / Momentum / Adam / AdamW，**AdamW 修了 Adam 的什么**
- [ ] 学习率是**最重要的超参**：怎么快速找到合适的数量级（LR range test）
- [ ] 学习率调度：warmup / cosine / step，以及各自适合的场景
- [ ] Batch size 与学习率的关系、梯度累积模拟大 batch
- [ ] 正则化：Dropout、权重衰减、Label Smoothing、Early Stopping
- [ ] 归一化：BatchNorm / LayerNorm / RMSNorm 的区别与适用场景
- [ ] 归一化层在 `train` / `eval` 下的行为差异（这是最常见的隐蔽 bug 来源）
- [ ] 过拟合与欠拟合：**怎么从 loss 曲线的形状判断**，而不是靠猜
- [ ] 梯度消失 / 爆炸：怎么从梯度范数发现、怎么缓解
- [ ] 损失不下降的排查顺序（数据 → 学习率 → 初始化 → 损失函数）

### 练到什么程度

给一条不收敛的 loss 曲线，能列出至少 3 个可能原因并说清**各自该看哪个量来验证**。

## 6. 实验方法论

> 这一节不写代码，但它决定你的学习速度。**没有实验纪律的人，一年后还在重复同一个错误。**

### 必学

- [ ] 先让模型**过拟合一个极小数据集** —— 最有效的 debug 手段，没有之一
- [ ] 一次只改一个变量，并记录它的影响
- [ ] 训练 / 验证 / 测试集的划分，以及**绝不根据测试集调参**
- [ ] 数据泄漏的常见来源（归一化统计量、时间序列、重复样本）
- [ ] 指标选择：类别不平衡时准确率会骗人（改看 P / R / F1 / AUC）
- [ ] 随机种子的作用：多次运行才能判断差异是否显著
- [ ] 实验记录该写什么：配置、曲线、结论、**下次准备试什么**
- [ ] 用 git 管理实验代码：每个结论对应一个能复现的提交

### 练到什么程度

任何一次「变好了」，你都能回答：**是哪个改动带来的、幅度多大、换一个种子还成立吗。**

## 最小必学清单

如果你只想先学最核心的：

1. PyTorch 张量形状操作（`view` / `reshape` / `permute`）
2. 手写一遍训练循环：前向 → 损失 → `zero_grad` → `backward` → `step`
3. **手推两层网络的反向传播**，并用 NumPy 对拍一次
4. 交叉熵损失与 MLE 的关系
5. 广播规则（NumPy 与 PyTorch 通用）
6. 学习率是超参里最重要的一个；会看 loss 曲线判断过拟合
7. `model.eval()` 改了什么；归一化层在 train / eval 下的差异
8. 先在小数据集上过拟合，再上真实数据
9. 固定随机种子，让实验可复现
